AUTO+ Maroc

Plateforme intelligente de mise en relation automobilistes ↔ mécaniciens au Maroc — diagnostic assisté par IA, SaaS garage & marketplace pièces.

Filière : Big Data & Intelligence Artificielle Niveau : Bac+5 Année : 2025–2026 Équipe : Fatima Zahra & Marouane
1

Contexte & problématique

Le marché de l'entretien automobile au Maroc est fragmenté et informel. Les automobilistes peinent à identifier des mécaniciens fiables, transparents sur les prix et géolocalisés, tandis que les ateliers indépendants souffrent d'une visibilité limitée et de difficultés d'acquisition client. L'absence de données structurées sur ce secteur empêche toute optimisation du service.

Problématique : comment concevoir et déployer une plateforme data-driven qui réduit l'asymétrie d'information entre automobilistes et mécaniciens, en exploitant le Big Data et l'IA pour le matching, la recommandation et l'analyse comportementale ?

Choix de la niche

Parmi plusieurs pistes explorées, nous avons choisi de nous concentrer sur la mise en relation automobilistes ↔ garages/mécaniciens indépendants, un segment à fort volume, peu digitalisé, et pour lequel un pipeline de données (annuaire de garages, avis, prix) permet de construire rapidement de la valeur mesurable (scoring, recommandation).

  • Marketplace bi-face : automobilistes (B2C) et garages (B2B / SaaS)
  • Différenciation : agent IA de diagnostic en darija/français
  • Monétisation envisagée : commission mise en relation, abonnement SaaS garage, marketplace pièces
À compléter : critères de sélection de la niche, alternatives écartées et pourquoi, retours du prof/mentors…

Architecture technique choisie

  • Backend : Node.js + Express (API REST)
  • Base de données : PostgreSQL + extension PostGIS (géolocalisation)
  • Mobile : React Native (Expo)
  • ML / Data : Python 3.10, notebooks Jupyter
  • Data Lake : events applicatifs en Parquet, partitionnés par date
  • Infra : Docker + Docker Compose (API + DB)

Création de la base de données PostgreSQL

Terminé

Mise en place de la base autoplus via Docker (image postgis/postgis:16-3.4) et d'une première table garages servant d'annuaire pour la vitrine des mécaniciens/ateliers.

-- api/migrations/001_create_garages.sql
CREATE EXTENSION IF NOT EXISTS postgis;

CREATE TABLE IF NOT EXISTS garages (
  id, nom, categorie, adresse, ville, telephone,
  note, nb_avis, lien_fiche (clé de dédup), source,
  a_completer, geom GEOGRAPHY(POINT, 4326),
  scraped_at, created_at, updated_at
);

-- index sur la ville + index spatial GIST sur geom
  • Extension PostGIS activée pour la future géolocalisation des garages
  • Champ lien_fiche unique : sert de clé de déduplication entre imports successifs
  • Index sur ville et index spatial GIST sur geom
  • Connexion vérifiée via l'endpoint /health de l'API ({"status":"ok","db_time":"..."})
