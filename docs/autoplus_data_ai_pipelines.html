Étape 02 — Cleaning
Nettoyage & Validation
Problèmes réels à gérer dans les données marocaines :

  • Plaques mal saisies → normalisation regex : A-12345-1
  • Coûts aberrants → détection outliers (vidange à 50 DH ou 50 000 DH = erreur)
  • Dates incorrectes → intervention avant fabrication voiture = impossible
  • Doublons → même intervention même jour même garage = dédupliqué
  • Texte darija → normalisation Unicode, suppression caractères spéciaux

A2 — Entraînement

→ Interprétable, robuste, peu de données nécessaires

Phase 2 (+10k véhicules) : Neural Network
→ Plus précis, capture les interactions complexes

Target : valeur_marche_dh
Métrique : MAE (erreur absolue moyenne en DH)

XGBoost scikit-learn PyTorch (phase 2)

Modèle B — Recommandation de garages
B1 — Approche hybride
Content-Based + Collaborative Filtering
Content-based : match entre le problème déclaré et la spécialité du garage
score = similarity(probleme_user, specialites_garage)

Collaborative : les users avec profil similaire ont choisi quels garages ?
score += cf_score(user_id, garage_id)

Final score :
rank = α×content + β×cf + γ×distance + δ×rating

scikit-surprise sentence-transformers

Modèle C — Détection faux avis
C1 — Anomaly Detection
Isolation Forest + NLP
Signaux comportementaux :
  • Compte créé il y a moins de 24h + avis 5★ posté
  • Même IP → multiple comptes → avis même garage
  • Aucun RDV enregistré mais avis posté

Signaux NLP :
  • Texte trop générique (template-like)
  • Sentiment incohérent avec la note

Étape 03 — Intent Classification

Classification du message en intent avant d'appeler le LLM — plus rapide et moins coûteux.
