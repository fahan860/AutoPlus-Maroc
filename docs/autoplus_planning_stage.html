S6
Semaine 6 — Modèle A (Pricing Véhicule) + Modèle C (Faux Avis) + MLflow
4 – 10 août 2026
📊 ML Modèles A & C
▼
📊 Modèle A — Estimation valeur véhicule
  • Split temporel : données 2025 → train (70%), val (15%), test (15%)
  • Phase 1 : entraîner XGBoost (robuste avec peu de données)
  • Tuning hyperparamètres avec Optuna
  • Métrique : MAE (erreur absolue moyenne en DH)
  • Logger dans MLflow : mlflow.log_param("n_estimators", 200), mlflow.log_metric("mae", X)
  • Exposer via FastAPI : POST /predict/vehicle-value
XGBoost scikit-learn MLflow Optuna FastAPI
🚨 Modèle C — Détection faux avis
  • Règles comportementales :
  • → Compte créé moins de 24h + avis 5★ = flag automatique
  • → Même IP + multiple comptes + avis même garage = flag
  • → Aucun RDV enregistré + avis posté = flag
  • Isolation Forest sur features comportementales
  • CAMeL-Tools NLP : texte trop générique ou sentiment incohérent avec la note
  • Exposer via FastAPI : POST /predict/review-fraud
Isolation Forest CAMeL-Tools scikit-learn FastAPI
🏙️ Terrain + Académique
  • Interviews 10 beta users : "qu'est-ce qui vous a bloqué cette semaine ?"
  • Rapport d'avancement N°6 : inclure métriques MLflow des deux modèles (MAE, F1-score), comparaison paramètres
✅ Résultat attendu fin de semaine
  • Modèle A (XGBoost pricing) loggé dans MLflow avec MAE calculé
  • Modèle C (détection faux avis) actif — zéro faux avis visible automatiquement
  • 2 endpoints FastAPI ML en ligne : /predict/vehicle-value, /predict/review-fraud
